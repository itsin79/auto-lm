# پلاگین اتو ال‌ام

پلاگین MCP خصوصی برای تبدیل توضیحات فارسی کاربر درباره وضعیت خودرو به پرونده و گزارش در فرم ۱۶ موردی اتو ال‌ام. مدل ChatGPT توضیحات را به ورودی ساختاریافته ابزارها تبدیل می‌کند؛ سرور به کلید API مدل نیاز ندارد.

## ابزارها

- `get_inspection_catalog`: خواندن کلیدها، وضعیت‌ها و قواعد ثبت.
- `prepare_inspection`: ایجاد پرونده و گزارش مقدماتی یا تکمیل‌شده، با شناسه درخواست برای جلوگیری از ثبت تکراری.
- `update_inspection`: اصلاح با کنترل نسخه برای جلوگیری از بازنویسی هم‌زمان.
- `get_inspection_report`: متن گزارش، موارد باقی‌مانده و لینک مشاهده/چاپ و دریافت JSON.
- `list_inspections`: جست‌وجوی پرونده‌های متعلق به کاربر جاری.
- `sync_inspection_to_admin`: همگام‌سازی دوبارهٔ یک گزارش ذخیره‌شده به پنل مدیریت.

فقط گفته‌های کاربر ثبت می‌شوند. هر یافته شاهدی عیناً از متن کاربر دارد؛ موارد ناگفته بررسی‌نشده می‌مانند. گزینه `remaining_healthy_evidence` فقط برای اعلام صریح سلامت سایر موارد توسط کاربر است؛ تشخیص معنای گفته کاربر وظیفه مدل است و سرور صرفاً وجود نقل قول در متن را اعتبارسنجی می‌کند. موارد خارج از فرم مثل ترمز در `additional_notes` حفظ می‌شوند و در امتیاز دخالت ندارند. امتیاز کل تنها پس از پاسخ هر ۱۶ مورد ساخته می‌شود؛ هشدار شاسی مستقل است. همه گزارش‌ها با عنوان «به روایت کاربر» ارائه می‌شوند.

## اجرا و بررسی

Node.js 22.13 یا جدیدتر لازم است. نصب و ساخت با راهنمای Sites انجام می‌شود. فرمان‌های مستقل پس از نصب:

```sh
node --test tests/mcp.test.mjs
npm run db:generate
npm run build
npm run dev -- --hostname 127.0.0.1 --port 5173
```

در پیش‌نمایش محلی، `/signin-with-chatgpt?return_to=/` ورود آزمایشی Sites را فعال می‌کند. این شبیه‌سازی وارد ساخت نهایی نمی‌شود. پایگاه داده محلی از تولید جداست؛ مهاجرت‌های `drizzle/` را طبق README استارتر روی D1 محلی اعمال کنید. مهاجرت تولید را Sites هنگام انتشار اعمال می‌کند.

`POST /mcp` از کشف `2026-07-28` و آغاز استاندارد MCP پشتیبانی می‌کند. `GET /reports/:id` گزارش فارسی A4 و `GET /reports/:id/export` فایل سازگار با اپ محلی را برمی‌گرداند. دکمه چاپ از پنجره بومی مرورگر برای ذخیره PDF استفاده می‌کند و سرور فایل PDF نمی‌سازد.

## همگام‌سازی با پنل کارشناسان

پس از ساخت یا اصلاح گزارش، MCP آن را خودکار به `POST /api/mcp/inspections` می‌فرستد، مشروط به اینکه این متغیرها در محیط Sites یا فایل محلی `.dev.vars` تنظیم شده باشند:

- `AUTOLM_ADMIN_SYNC_URL`: در اجرای محلی `http://127.0.0.1:4173` تا گزارش به اپ محلی و SQLite محلی فرستاده شود.
- `AUTOLM_ADMIN_SYNC_TOKEN`: توکن محرمانهٔ مشترک با سرور پنل.
- `AUTOLM_DEFAULT_INSPECTOR`: نام کارشناس پیش‌فرض، مانند `سفیدگری`؛ اگر گزارش نام کارشناس دیگری داشته باشد، همان نام گزارش استفاده می‌شود.
- `AUTOLM_LOCAL_MCP_OWNER`: شناسهٔ ثابت مالک گزارش‌ها برای MCP محلی؛ فقط وقتی میزبان درخواست `localhost` یا `127.0.0.1` است استفاده می‌شود.
- توکن `AUTOLM_ADMIN_SYNC_TOKEN` باید با `AUTOLM_MCP_SYNC_TOKEN` اپ محلی در فایل `.env` ریشه یکسان باشد.

سرور محلی با `npm run dev -- --hostname 127.0.0.1 --port 5173` روی `http://127.0.0.1:5173/mcp` در دسترس است و `.dev.vars` گزارش‌ها را به اپ محلی روی درگاه `4173` می‌فرستد. اپ محلی را با `npm start` اجرا کنید تا توکن `.env` بارگذاری شود. این فایل فقط محیط محلی را تنظیم می‌کند؛ آدرس `*.chatgpt.site` به MCP منتشرشده وصل است و از تنظیم محلی اثر نمی‌گیرد. برای استفاده از دادهٔ لوکال، کلاینت MCP باید به endpoint محلی بالا وصل شود. ورودی فقط به کارشناس فعال با نام دقیقاً همسان تخصیص می‌گیرد؛ اگر کارشناس وجود نداشته باشد MCP خطا را در `admin_sync` گزارش می‌کند. برای تلاش مجدد ابزار `sync_inspection_to_admin` را با شناسه گزارش فراخوانی کنید. فایل‌های `.env` و `.dev.vars` را محرمانه نگه دارید.

### اتصال ChatGPT به MCP محلی

ChatGPT از راه دور به `127.0.0.1` دسترسی ندارد. برای استفاده از دیتابیس محلی، `npm start` و سرور MCP بالا را اجرا کنید، سپس Secure MCP Tunnel را به MCP روی درگاه `5173` وصل کنید و یک custom MCP با گزینهٔ Tunnel در ChatGPT بسازید. این اتصال از پلاگین منتشرشدهٔ «اتو ال‌ام» جداست؛ نسخهٔ `*.chatgpt.site` به `.dev.vars` محلی دسترسی ندارد. مالک `local-gpt` فقط برای درخواست‌های loopback در حالت محلی استفاده می‌شود. شناسهٔ tunnel و کلید اجرای آن از تنظیمات Platform شما می‌آیند.

## دسترسی

Sites دسترسی به سایت خصوصی و هویت فرستاده‌شده از ChatGPT را بررسی می‌کند. سرور شناسه `oai-authenticated-user-id` تزریق‌شده توسط Sites را کلید مالکیت قرار می‌دهد. تمام خواندن‌ها و نوشتن‌های D1 به مالک مقیدند. این اعتماد فقط پشت درگاه Sites معتبر است؛ این کد را با اعتماد به هدرهای ارسالی مستقیم از اینترنت روی میزبان دیگری منتشر نکنید. هیچ داده‌ای از localStorage مرورگر خودکار به سرور فرستاده نمی‌شود.

## اتصال

انتشار سایت، پلاگین خصوصی متناظر را ایجاد می‌کند. همان پلاگین را نصب کنید؛ پلاگین دوم نسازید. بعد از نصب در ChatGPT، گفت‌وگوی تازه‌ای باز کنید، `@` را تایپ و «اتو ال‌ام» را انتخاب کنید.

نمونه: «پژو ۲۰۶ مدل ۱۳۹۹، کارکرد ۸۵۰۰۰. موتور صدای غیرعادی دارد و لاستیک‌های جلو فرسوده‌اند. گزارش آماده کن.» سپس می‌توانید موارد دیگر را تکمیل یا گزارش را اصلاح کنید.

## انتقال به اپ محلی

اگر همگام‌سازی امن پیکربندی نشده، در صفحه گزارش «دریافت برای اپ اتو ال‌ام» را بزنید. در اپ محلی وارد شوید، تب «کارشناسی‌های قبلی» و «ورود گزارش ChatGPT» را انتخاب و JSON را باز کنید. مسیر خودکار یک‌طرفه است؛ نسخه‌های جدیدتر گزارش MCP همان پرونده را در پنل به‌روزرسانی می‌کنند و تاریخچه و منشأ گفته‌ها را نگه می‌دارند.
