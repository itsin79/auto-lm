# راهنمای اجرای و استفاده از اتو ال‌ام

## نیازمندی‌ها

- Node.js نسخهٔ 22.13 یا جدیدتر.
- برای اجرای اپ اصلی، نصب کتابخانهٔ خارجی لازم نیست.
- نسخهٔ ZIP بدون پوشهٔ پلاگین و بدون نیاز به MCP آماده شده است.

## اجرای محلی

از پوشهٔ ریشهٔ پروژه اجرا کنید:

```sh
npm start
```

سپس این نشانی‌ها را باز کنید:

- اپ کارشناس: `http://127.0.0.1:4173/`
- پنل مدیریت: `http://127.0.0.1:4173/admin/`

در اجرای محلی تازه، نام کاربری و رمز مدیر هر دو `admin` هستند. برای ایجاد حساب کارشناس وارد پنل شوید و مشخصات، شمارهٔ موبایل، رمز و وضعیت فعال را ثبت کنید. کارشناس با شمارهٔ موبایل و رمز ساخته‌شده وارد اپ می‌شود.

درگاه را با `PORT` و مسیر پایگاه داده را با `AUTOLM_DB_PATH` عوض کنید. سرور محلی به‌طور پیش‌فرض فقط روی loopback گوش می‌دهد.

## ثبت کارشناسی

1. با حساب کارشناس وارد شوید و «ثبت کارشناسی جدید» را انتخاب کنید.
2. مدل خودرو را از پیشنهادها انتخاب کنید یا نام را دستی وارد کنید. سال، کارکرد و اجزای پلاک را ثبت کنید.
3. «تأیید و ادامه» را بزنید؛ پیش‌نویس از اولین داده ساخته و خودکار ذخیره می‌شود.
4. در بخش‌های بدنه، موتور، داخل کابین و لاستیک‌ها برای هرکدام از ۱۶ مورد وضعیت تعیین کنید.
5. در صورت نیاز، یادداشت کوتاه اضافه و ذخیره کنید. یادداشت در حال ویرایش تا زمان تأیید در گزارش نمایش داده نمی‌شود.
6. بعد از پاسخ به همهٔ موارد، گزارش کامل می‌شود. شاسی و ستون‌ها هشدار جداگانه دارند.
7. در گزارش، «دانلود PDF» را بزنید. فایل فارسی A4 در خود مرورگر ساخته و مستقیم دانلود می‌شود. از کارت گزارش تکمیل‌شده در تاریخچه نیز می‌توانید PDF را دانلود کنید.

## تاریخچه

در تب «کارشناسی‌های قبلی» نام خودرو، پلاک یا شناسه را جست‌وجو کنید. فیلتر وضعیت و ترتیب جدیدترین/قدیمی‌ترین در دسترس است. برای ادامهٔ پیش‌نویس، کارت آن را باز و «ادامه» را انتخاب کنید.

## پنل مدیریت

- بخش «کارشناسان» برای ساخت و ویرایش حساب‌ها و فعال/غیرفعال کردن دسترسی است.
- بخش «پرونده‌ها» برای جست‌وجو، فیلتر، مشاهدهٔ جزئیات و گزارش استفاده می‌شود.
- برای خروجی Excel ردیف‌های موردنظر را انتخاب و خروجی را دریافت کنید.
- هنگام انتقال دادهٔ قدیمی، فقط پرونده‌های معتبر و متعلق به شمارهٔ کارشناس منتقل می‌شوند.

## آزمون‌ها و اشکال‌زدایی

از ریشهٔ پروژه اجرا کنید:

```sh
npm test
```

آزمون HTTP یک سرور موقت روی `127.0.0.1` باز می‌کند. اگر سیستم اجازهٔ ایجاد socket محلی ندهد، تست را در محیطی اجرا کنید که loopback در دسترس باشد. هشدار `node:sqlite` در Node 22 آزمایشی‌بودن API را اعلام می‌کند؛ به‌تنهایی نشانهٔ شکست آزمون نیست.

## پشتیبان‌گیری و بازیابی

برای پشتیبان‌گیری از SQLite محلی، سرور را متوقف کنید و سپس `.data/` را کپی کنید. هنگام خاموش‌کردن سرور، فایل پایگاه داده و journalهای SQLite در وضعیت سازگار قرار می‌گیرند. مسیر جایگزین را با `AUTOLM_DB_PATH` تنظیم کنید.

## حریم داده و محدودیت گزارش

- دادهٔ واقعی نمونه به‌طور خودکار ساخته نمی‌شود.
- رمز و فایل‌های محیطی را به ZIP یا Git اضافه نکنید.
- گزارش، ثبت وضعیت‌های واردشده است؛ جایگزین بازدید حضوری، تشخیص قطعی، قیمت‌گذاری یا گواهی ایمنی نیست.
- امتیاز عددی فقط پس از پاسخ هر ۱۶ مورد ارائه می‌شود و شاخص رسمی بازار محسوب نمی‌شود.
